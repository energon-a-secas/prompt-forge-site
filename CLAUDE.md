# CLAUDE.md: Prompt Forge

Prompt Forge: character prompt builder and image tag formatter for local models (promptforge.neorgon.com)

**Live:** promptforge.neorgon.com · **Port:** 8842

## Run

```bash
make serve
```

Then open http://localhost:8842. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Data

- `localStorage['c']`
- `localStorage['prompt-forge-state']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
